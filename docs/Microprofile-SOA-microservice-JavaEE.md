### MicroProfile
!!! note annotate "MicroProfile"

    - Les composants de l'API MicroProfile sont basés sur le modèle Java EE. 
    - Est un ensemble de spécifications open source pilotées par la communauté Eclipse Fondation qui définissent une plateforme de microservices Java d'entreprise.
    - MicroProfile en bref
        - [https://www.ibm.com/docs/fr/cics-ts/5.6?topic=server-developing-microservices-microprofile](https://www.ibm.com/docs/fr/cics-ts/5.6?topic=server-developing-microservices-microprofile)
        - Aujourd'hui l'évolution efficace vers le monde du cloud: les microservices devient un secteur de recherches de plusieurs entreprises qui recherchent des frameworks et des API qui leur permettraient d'évoluer efficacement vers le monde du cloud et des microservices,
        - MicroProfile: Les composants de l'API MicroProfile sont basés sur le modèle Java EE. Est un ensemble de spécifications open source pilotées par la communauté Eclipse Fondation qui définissent une plateforme de microservices Java d'entreprise.
        - Les technologiques se concentre principalement sur les services REST et CDI pour l'interaction entre les microservices.
        - Il existe plusieurs environnements d'exécution où vous pouvez exécuter l'API MicroProfile. Nous mentionnerons ici les options les plus populaires :
    1. Serveur d'applications WildFly / JBoss EAP (avec pack d'extension)
       2. Quarkus
       3. Serveur d'application Payara
       4. IBM OpenLiberty
       5. Tomtribu TomEE

### CDI
!!! note annotate "CDI"

    - CDI définit un ensemble de services qui gèrent l'injection et le cycle de vie des objets dans un environnement d'exécution Enterprise Java.

### JAX-RS
!!! note annotate "JAX-RS"

    - JAX-RS est une API Java pour les services Web RESTful.

### JMX
!!! note annotate "JMX"

    - JMX: Java Management Extensions : il s'agit d'un standard Java cad une API Java qui définot des classes et une architecture à respecter.
    - Cette technologie permet la monitoring d'application Java
    - L'objectif de JMX est de visualiser les performances des applications d'un système distribué: 
      visualiser les statistiques d'une application (ressources de processeurs , la mémoires ou nombre de threads actifs sur la JVM)
